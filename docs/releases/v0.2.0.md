# mcp-breaker v0.2.0 — Semantic Tracker, Graph Ledger, Dashboard, Homebrew

**Release date:** 2026-08-29  
**Tag:** `v0.2.0`

Second release adding semantic stagnation detection, graph loop ledger, TUI dashboard, and Homebrew packaging.

---

## Highlights

- **Semantic stagnation tracker** — cosine similarity (≥ 0.88) across tool result texts; spec Test Case B
- **Sliding-window graph ledger** — detects A→B→A→B tool invocation loops; blocks and pauses until dashboard resume
- **TUI dashboard** — `mcp-breaker dashboard` shows live metrics, stream, cosine scores
- **Model management** — `mcp-breaker models download|status` for All-MiniLM-L6-v2 ONNX cache
- **Homebrew formula** — [`Formula/mcp-breaker.rb`](../../Formula/mcp-breaker.rb) + [install guide](../install/homebrew.md)

## Semantic tracker (Test Case B)

Compares embedding cosine similarity between turn **N** and **N−2** on `tools/call` **responses**. When similarity ≥ 0.88, appends the spec 3.3 intervention notice without killing the session.

Development without ONNX:

```bash
export MCP_BREAKER_MOCK_EMBED=1
```

Production with ONNX:

```bash
brew install onnxruntime
mcp-breaker models download
go build -tags=onnx -o mcp-breaker ./cmd/mcp-breaker  # optional ONNX build tag
```

---

## Graph ledger

Tracks the last 10 tool turn keys (`tool:argHash`). Trips on tail pattern **A,B,A,B** (and extended **A,B,A,B,A,B**). Blocks the request and pauses until:

```bash
mcp-breaker dashboard   # press R to resume
```
