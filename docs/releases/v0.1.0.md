# mcp-breaker v0.1.0 — Initial Release

**Release date:** 2026-08-29  
**Tag:** `v0.1.0`

First public release of **mcp-breaker**, a semantic MCP circuit breaker that proxies JSON-RPC traffic between AI clients and MCP servers over stdio.

---

## Highlights

- **Stdio JSON-RPC proxy** — transparent wrap layer compatible with Cursor, Claude Desktop, Cline, and any MCP stdio client
- **Tool echo detector** — blocks the 3rd consecutive identical `tools/call` per tool before it reaches the backend server
- **Graceful intervention** — returns structured MCP error results instead of crashing the agent session
- **Zero runtime dependencies** — single static Go binary (~3 MB)
- **Built-in demo** — `make demo` runs end-to-end with no MCP configuration required

---

## What's included

### Core

| Component | Description |
|-----------|-------------|
| `mcp-breaker wrap` | CLI command to launch and proxy any MCP server process |
| `pkg/proxy` | Newline-delimited JSON-RPC framing, bidirectional session proxy |
| `pkg/breaker` | Echo detector with per-tool SHA-256 hash ring (size 5) |
| `pkg/protocol` | MCP `tools/call` types and intervention payloads |
| `fakemcp` | Built-in fake MCP server for local testing |

### Detection behavior (Echo Breaker)

- Intercepts every `tools/call` JSON-RPC request
- Tracks consecutive identical argument hashes per tool name
- Forwards calls 1 and 2; **blocks call 3** with:

  ```
  Error: Command [<tool>] generated identical failures across consecutive loops.
  Do not retry without modifying parameters.
  ```

- Resets counter when arguments change; isolates counters per tool
- All other MCP methods (`initialize`, `tools/list`, notifications) pass through unchanged

## Quick start

```bash
git clone https://github.com/shunvel/mcp-breaker.git
cd mcp-breaker
make build
make demo
```

Wrap an MCP server:

```bash
./mcp-breaker wrap -- npx -y @modelcontextprotocol/server-filesystem /tmp
```

---

## Client configuration example

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "/path/to/mcp-breaker",
      "args": ["wrap", "--", "npx", "-y", "@modelcontextprotocol/server-filesystem", "/tmp"]
    }
  }
}
```

## Known limitations

- **Semantic stagnation detection** (spec Test Case B) is not yet implemented — placeholder only
- **No `init` command** — MCP configs must be wrapped manually
- **No TUI dashboard** — planned for a future release
- **No pre-built binary downloads** — build from source for now
